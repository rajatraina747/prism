# Third-Party Security, Product & Engineering Review — September 2026 (v1.7.3 → v1.8.0)

Point-in-time review of the whole codebase at `73c0fb1` (v1.7.3 + 3 unreleased
commits) by an outside team: cybersecurity, product/design, engineering
health. Re-tested every item of [AUDIT-2026-07.md](AUDIT-2026-07.md), covered
everything added since (player, torrent parity, extension), ran `cargo audit`,
`npm audit`, and read the installed Tauri 2.11 source where behaviour mattered.

**Headline:** the application code was already unusually well-hardened
(arg-injection terminators, path containment, whitelisted settings, least-
privilege capabilities, signed updater, opt-in crash reporting). The real risk
sat *around* the code: an unpinned, unverified build-time supply chain that
the signed updater then vouched for; a GPL licensing exposure in the macOS
bundle; the entire July backlog still open; and defense-in-depth gaps in the
newest surface (the mpv player). No critical, remotely exploitable flaw.

**Status column:** what shipped in v1.8.0 vs what remains open.

## A. Security

| # | Sev | Finding | Status (v1.8.0) |
|---|-----|---------|-----------------|

| SEC-2 | Medium | Write roots were all of `$HOME` (`~/Library/LaunchAgents`, `~/.ssh`, Windows Startup all writable). | SEC-6 | Medium | `cargo audit`: 8 vulns (quick-xml ×3, h2, rkyv); `npm audit --omit=dev`: 6; neither in CI. | **Fixed.** librqbit 8→9, `cargo update`, react-router 6→7, `npm audit fix` → both audits clean; both are CI jobs (`audit`), ignore list in `src-tauri/.cargo/audit.toml`. |

## Verification performed

- `cargo clippy --all-targets -- -D warnings`: clean. `cargo test --lib`: 38 passed.
- `npx tsc --noEmit`, `npm run lint` (0 errors), `vitest`: 150 passed.
- `cargo audit`: 0 vulnerabilities (17 unmaintained/unsound warnings, all transitive). `npm audit --omit=dev`: 0.
- `scripts/fetch-sidecars.sh macos`: every download verified against the lock; `yt-dlp --version` and `deno --version` run from the fetched binaries. The libmpv-wrapper download + checksum and the license-collection loop (74 formulae, incl. ffmpeg/x264/x265) were verified in isolation. **Not verified locally:** the unchanged `dylibbundler` step of `bundle-libmpv-macos.sh` did not finish on the review machine (two ffmpeg kegs installed side by side; it spun without writing output and was stopped) — the next tagged build's macOS job log is the check, exactly as for v1.7.2.
- `cargo build` (debug) links; the GUI was not exercised in this session — smoke-test the player and a real download before tagging.

```sh
npm audit --omit=dev --audit-level=high
(cd src-tauri && cargo audit)
scripts/update-sidecars.sh && git diff scripts/sidecars.lock   # review, then commit
```
