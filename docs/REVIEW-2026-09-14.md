# Third-Party Review — 14 September 2026 (v1.8.0 → v1.8.1)

Point-in-time review of v1.8.0 (`a051dd4`) by an outside team acting as
cybersecurity, product, design and engineering. Re-verified the September
hardening ([AUDIT-2026-09.md](AUDIT-2026-09.md)), covered the surface it did
not (Transfers page, player chrome, extension, librqbit persistence), and
turned the findings into the arcs now in [ROADMAP.md](../ROADMAP.md).
Every item below was checked against the code, and the two P0 bugs against
the maintainer's live app data.

## P0 — bugs found in use (fixed in v1.8.1)

**Finished downloads never reached the Library.** The archive effect in
`src/stores/AppProvider.tsx` was a 2 s timer keyed on the whole queue array;
every progress tick rebuilt the array and re-armed the timer, so with any
transfer active nothing was ever archived. The Transfers page hides finished
rows, so completed items vanished. Fixed by keying the effect on the set of
terminal ids; regression test added.

**Flat multi-file torrents shared one folder.** `torrent.rs` passed an
explicit `output_folder`, which disables librqbit's default of a
`<dest>/<name>` subfolder for multi-file torrents. Two F1 packs with the same
inner file names were writing interleaved pieces into one
`02.Race.Session.mp4`. Fixed by deriving the folder from the metainfo before
the add (list-only fetch for magnets without cached metadata), sanitising the
name to one path component, refusing a folder already owned by a different
info hash, and carrying the effective folder into the completion event and
Library. Six Rust tests added.

## Security

The September fixes hold: no raw mpv permissions in any capability, mpv runs
`config=no load-scripts=no ytdl=no`, `--` terminator before URLs, https-only
blocklist, capped fetches, SHA-pinned actions, empty `audit.toml` ignore
list, signed updater, Sentry doubly gated and scrubbed, extension has one
permission and no native messaging, no localhost listener anywhere. No
critical or remotely exploitable-without-user-action flaw.

## Product & engineering health

- ffmpeg is required for merged 4K, audio extraction, embedding and
  SponsorBlock but was never stated. **README fixed 1.8.1**; bundling a static
  LGPL ffmpeg is the v2.0 answer.
- README claimed macOS Intel with no such build job. **Fixed 1.8.1.**
- README screenshots (July) predate Transfers, the detail panel and the player.
- No `SECURITY.md`, issue templates, CONTRIBUTING; About has no "Report a bug".
- Bundle id `com.prism.app` implies ownership of prism.app. Decide the
  migration to `com.rainacorp.prism` at the start of v2.0.
- TypeScript strictness is off; eslint disables `no-unused-vars` /
  `no-explicit-any`. 16 Playwright tests never run in CI.
- 2 `log::` call sites in all of Rust; "Log level" is cosmetic for the backend.
- 7.4 MB of PNG logos (one unreferenced) ship in every installer; 32 of 41
  shadcn files and ~20 Radix deps unused; two reqwest versions in the lock.
- `lib.rs` 1,869 lines / 23 commands; `torrent.rs` thinly tested; the five
  largest page components have zero tests.
- `--force-ipv4` hardcoded; error classification pattern-matches English.
- Minisign key has no backup/rotation doc; updater endpoint is the repo.
- Positioning: "download manager" framing vs no plain-HTTP downloads.

## UX

Good bones: pure guarded reducer, events not polling, `SwarmHealth` copy,
confirm dialogs that name consequences, undo toasts, SetupCard, quality
shortfall surfaced, single icon family, persisted filter/sort.

High: light-mode tokens missing for success/warning/sidebar (**fixed 1.8.1**);
Settings controls unlabelled for assistive tech; drop submitted twice
(**fixed 1.8.1**); quiet hours indistinguishable from slot waiting; failure
suggestion shown in the wrong place and parse errors unclassified; no
virtualization plus per-row `backdrop-filter`; rows not focusable and
`aria-selected` on `listitem`; grip and global ↑/↓ both fire.

Medium: 20-row flat "Downloads" settings section; two bandwidth limits in two
units; settings written per keystroke (**fixed 1.8.1**); Library delete with
no undo; "Undo" on cancel restarts from 0%; Library/Subscriptions lack the
Transfers list model; terminology drift (transfer/queue/download/history);
three post-add behaviours; ephemeral preset silently overridden by per-site
memory; 45 s torrent picker with no escape hatch; unskippable splash; empty
states without actions; no global shortcuts or native menu; legal pages
always return to Settings; picker rows and tabs lack semantics; no
reduced-motion support.

Jargon without help: info hash, DHT/PEX, pieces map, uTP, LSD, socks5h, p2p
blocklist, announce URLs, remux, VP9/AV1, ratio.
